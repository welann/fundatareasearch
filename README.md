# Fun Data Research

这个仓库用于沉淀一些有趣的数据分析页面。当前形态是一个可直接部署到 Vercel 的静态 HTML 站点：

- `index.html`：汇总主页面，负责展示报告入口。
- `research/mmk_sz.html`：Telegram 数据社科田野报告。
- `research/hanbalongwang_summary.html`：《憨巴龙王》小节化深度阅读报告。
- `telegram_three_year_analysis/index.html`：研究生三年频道记录回看。
- `telegram_trading_analysis/index.html`：交易标签、本人投资观点与时间线分析。
- `telegram_media_diary/index.html`：书、电影、番剧、电视剧、纪录片与漫画的原话阅览手账。

所有页面都尽量保持单文件交付，不依赖后端服务，适合本地打开、静态托管和长期归档。

## 当前报告

### TG Dating Research Report

`research/mmk_sz.html` 是一份基于 Telegram 频道导出数据整理而成的可搜索、可阅读、带匿名化处理的社科风格研究报告。

它不是原始数据备份，而是把频道中的结构化字段、随机样本、文本摘抄和统计结果整合成了一份单文件 HTML 报告，适合浏览、检索和展示。

报告主要包含：

- 概览：对样本整体特征做摘要说明。
- 硬数据：展示全量记录数、抽样规模、消费中位数、评分均值等核心统计指标。
- 类型总评：对不同类型的评价模式做归纳。
- 评价语显微镜：从文本里提取高频表达、叙事习惯和评价语言。
- 亮点语句：展示有代表性的匿名化摘抄。
- 原始摘抄库：提供可折叠、可搜索的原始文本样本库，便于回查。

### 《憨巴龙王》小节化深度阅读

`research/hanbalongwang_summary.html` 是一份可搜索的单文件 HTML 阅读报告。

它把原始 PDF 按“语义小节”重新组织，而不是按页码切分。每个小节保留原页截图作为证据，同时提供内容整理、归纳总结、策略抽象、延展分析、风险提示和可继续追踪的变量。

报告主要包含：

- 小节卡片：按仓位、信息差、协议资产、KOL、广告层等主题组织。
- 原页截图：点击缩略图可放大校验原文。
- 搜索与筛选：支持按关键词、主题和风险等级定位小节。
- 主题索引：把跨页内容合并为可阅读的语义单元。
- 风险提示：区分可复用的决策框架和不可复制的营销、情绪或极端风险叙事。

### 研究生三年记录回看

`telegram_three_year_analysis/index.html` 汇总 2023 至 2026 年的频道记录，按主题、标签、情绪、投资经历和人生事件回看研究生阶段的变化。

报告主要包含：

- 主题与标签变化：观察不同时期的注意力分布。
- 情绪月度复盘：汇总可回查的情绪记录。
- 投资经历：展示与投资相关的记录，但不替代单独的投资观点分析。
- 人生事件时间线：按时间串联学习、生活和工作节点。

### Telegram 交易观点分析

`telegram_trading_analysis/index.html` 从交易相关标签、`#想法`、回复上下文和高置信交易记录中提取投资观点，并将“保存过的材料”与“本人明确表达的观点”分开处理。

当前口径下，报告保留 23 个交易标签、507 条标签命中和 327 条本人观点；103 条有正文的交易类 `#想法` 均进入观点时间线。

报告主要包含：

- 材料与观点分层：纯链接、待看记录、内容质量评价、转发和摘录不参与观点结论。
- 主题与月份分布：只使用本人观点统计风险、套利、期权、量化、市场与退出等主题。
- 六个阶段：从基础问题、数据试验，发展到市场结构、实战复盘和风险框架。
- 转折点：用原始消息连接观点变化。
- 时间线：可切换本人观点、`#想法`、标签材料库和全部相关记录。

目录中的 `analysis.json` 是可审计的结构化结果，`build_report.py` 和 `template.html` 用于从 Telegram 导出文件重新生成页面。

### 私人阅览档案

`telegram_media_diary/index.html` 从 `#书`、`#读书`、`#观剧`、`#纪录片` 和 `#漫画` 记录中，摘取明确属于本人的阅读与观看感悟。

当前口径下，共检查 272 条标签记录，保留 119 条有原始感悟的记录，涉及 86 部作品，时间覆盖 2023 年 2 月至 2026 年 8 月。纯收藏、待看链接和外部影评不进入正文；入选消息中的书摘及其他 Telegram 引用块按原顺序保留，并与本人感想分开排版。

页面主要包含：

- 精选胶片：横向浏览有代表性的原话片段。
- 时间档案：从早到晚串起不同作品留下的当时感受。
- 媒介筛选：支持书、电影、番剧、电视剧、纪录片和阅读随记。
- 搜索与排序：可按作品名或原话搜索，并切换时间方向。
- 原消息回查：每条摘录都保留对应的 Telegram 消息入口。

目录中的 `curation.json` 保存人工复核的消息 ID、作品名、媒介与阅读状态；`analysis.json` 是生成后的结构化摘录，`build_report.py` 和 `template.html` 用于重建页面。

## 本地查看

直接打开首页：

```bash
open index.html
```

也可以直接打开某个分页面：

```bash
open "research/mmk_sz.html"
open "research/hanbalongwang_summary.html"
open "telegram_three_year_analysis/index.html"
open "telegram_trading_analysis/index.html"
open "telegram_media_diary/index.html"
```

## 新增分析页面

后续新增静态报告时，建议遵循这个流程：

1. 简单的单文件报告放到 `research/`；包含生成脚本、结构化数据或其他配套文件的报告使用独立目录，并以 `index.html` 作为入口。
2. 在 `index.html` 的 `#reports` 区域复制一张 `.report-card`，修改标题、标签、摘要和 `href`。
3. 如果报告还没有完成，可以先使用 `.queue-card` 作为预留入口。
4. 保持每个分页面独立可访问，避免依赖本地数据文件或后端接口。

## Vercel 部署

这是纯静态项目，不需要构建命令。

推荐 Vercel 设置：

- Framework Preset: `Other`
- Build Command: 留空
- Output Directory: `.`
- Install Command: 留空

部署完成后，Vercel 会默认访问 `index.html`，其他 HTML 分页面可以通过首页卡片进入。

## 内容原则

- 数据报告应保留研究用途说明。
- 涉及个人、地点、作者、联系方式等信息时，需要做匿名化、脱敏或遮罩。
- 首页只做汇总导航，不承载过多分析细节。
- 分页面可以自由做搜索、图表、样本库、交互筛选等具体功能。
